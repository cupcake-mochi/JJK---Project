# Checklist de revisão

Rode antes de fechar qualquer versão. Marque cada item; o que não passar vira tarefa antes do lançamento.

## 1. Entrada do leitor novo

- [ ] Existe uma explicação de como o jogo funciona nas primeiras páginas, que cabe em uma página
- [ ] Ela diz **o que se rola**, **o que se ganha** e **como uma cena termina**
- [ ] Ela lista as peças da ficha, nomeadas
- [ ] Um leitor chega até a primeira rolagem sem precisar pular para outra seção
- [ ] Cada seção grande declara logo no começo se é para ler ou para consultar

## 2. Jargão

- [ ] Todo termo próprio do sistema é definido na primeira aparição, no corpo do texto
- [ ] Nenhuma definição aparece só no glossário
- [ ] Nenhuma abreviação é usada antes de ser expandida uma vez
- [ ] Termos emprestados de outros sistemas (CD, teste de resistência, ação bônus) são definidos, não presumidos

## 3. Colisão de termo — o levantamento

Este é o item mais caro de pular e o mais fácil de fazer.

- [ ] Existe uma lista de **todos** os termos com significado próprio no sistema
- [ ] Nenhum termo da lista carrega dois significados diferentes
- [ ] Nenhum conceito da lista tem dois nomes no corpo do texto
- [ ] Sinônimos que a mesa usa na fala estão amarrados no glossário, com o nome canônico marcado

Como fazer o levantamento rápido: extraia todas as palavras em maiúscula, em negrito e todas as entradas do glossário; ordene; procure duplicata e quase-duplicata. Quando encontrar colisão, renomeie **a mais nova ou a menos entranhada**, e antes de a comunidade adotar — depois de adotado o custo multiplica.

## 4. Exemplos

- [ ] Todo conceito tem pelo menos um exemplo
- [ ] Os exemplos têm nome próprio, não "um personagem qualquer"
- [ ] Pelo menos um exemplo mostra a conta inteira, passo a passo
- [ ] Pelo menos um exemplo mostra alguém **escolhendo**, não só executando
- [ ] Conceitos que se confundem com um vizinho têm tabela de contraste "é X / não é X"

## 5. Ordem e destaque

- [ ] Nenhum trecho abre pela exceção
- [ ] Regra rápida e exceção estão separadas visualmente, não só logicamente
- [ ] Nenhum parágrafo em prosa carrega mais de três casos paralelos (vira tabela)
- [ ] O texto segue a ordem da ficha sempre que possível
- [ ] Existe uma tabela de referência rápida de uma página

## 6. Voz

- [ ] Segunda pessoa, voz ativa
- [ ] Títulos de seção são substantivos simples
- [ ] Regras cujo motivo não é óbvio trazem o porquê em uma linha
- [ ] Nenhuma seção elogia o próprio sistema
- [ ] Fato principal e consequência/ressalva não estão amarrados por travessão na mesma frase quando dá pra separar em duas

## 7. Cara de texto de máquina

- [ ] Nenhuma seção tem o mesmo tamanho de todas as outras por acidente
- [ ] Nenhum hedge vazio ("pode ser interessante", "é importante notar que", "de certa forma")
- [ ] Nenhum parágrafo reafirma a pergunta antes de responder
- [ ] Nenhuma frase anuncia a tabela ou lista que vem a seguir ("a diferença é X:") quando a própria estrutura já diz o que é
- [ ] Conectivos de encher cortados ("além disso", "por outro lado", "em suma")
- [ ] Nenhum tricolon automático — três adjetivos onde um bastava
- [ ] Nenhuma antítese decorativa ("não é X, é Y") em texto de regra ou catálogo — teste apagando a metade negada: se a frase continua ensinando a mesma coisa, corte a antítese inteira, não só reduza a frequência. Exceção só para citação literal de epígrafe/fala já existente na fonte, pontuada exatamente como a fonte pontua
- [ ] Travessão não é a pontuação padrão do texto — se mais de um parágrafo em três abre ou corta frase com travessão fora do cabeçalho de catálogo ("**Nome** — descrição"), varie: dois-pontos, ponto e vírgula, parênteses ou ponto final
- [ ] Nenhuma seção termina resumindo o que acabou de dizer
- [ ] Nenhuma seção abre com frase de princípio/slogan antes da regra ("Neste sistema, ninguém morre por causa de um número")
- [ ] Nenhuma frase diz ao leitor como se sentir em vez de dizer regra ("é para você confiar nisso"), nem repete em prosa uma implicação que a regra já deixou óbvia
- [ ] Nenhum parágrafo reexplica o porquê ou o efeito de uma regra que já tem seção dona em outro lugar do material
- [ ] Todo termo deixado sem definição por "já ter dono em outro capítulo" foi conferido de verdade — o capítulo dono existe e está escrito, não é suposição
- [ ] Nenhum jargão do sistema foi trocado por vocabulário genérico de fantasia emprestado de fora ("poder", "barreira mágica" em vez do termo que o próprio sistema já usa)
- [ ] O corte de 20% foi tentado em pelo menos as três seções mais longas

## 8. Consistência com o resto do material

- [ ] Todo número que aparece no texto confere com a tabela de origem
- [ ] Toda referência cruzada a seção aponta para o lugar certo (renumeração quebra isso silenciosamente)
- [ ] O glossário cobre todos os termos e nenhum termo morto
- [ ] A ficha usa exatamente os mesmos nomes que o texto

## 9. Prova final

- [ ] Alguém que nunca leu o material chegou até a primeira rolagem sozinho
- [ ] As perguntas que essa pessoa fez em voz alta foram anotadas literalmente
- [ ] Cada uma virou item de conserto, mesmo aquelas cuja resposta já estava escrita

A última linha é a que mais dói e a que mais rende: **se a pessoa perguntou, o texto escondeu bem demais.** Não interessa que a resposta estivesse na página 12.
